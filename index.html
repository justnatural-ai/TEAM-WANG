03排序原则落实固定编排依据

先复合后孤立胸 / 背 / 肩主项（复合推拉）排前，辅项（孤立夹 / 飞鸟 / 平举 / 面拉）排后。
先髋伸主力后补细节臀腿默认组合：罗马尼亚硬拉 → 史密斯臀桥 / 髋推 → 45°臀腿举 → 绳索后踢腿（髋伸复合主力在前，孤立补细节在后）。
大肌群先于小肌群六大部位菜单固定顺序：胸 → 背 → 肩 → 臀腿 → 手臂 → 核心。
部位内其余细节：臂部按「屈肘（弯举类）先于伸肘（下压 / 臂屈伸类）」；核心卷腹类先于转体类。全部为固定组合，点选部位即弹出该部位整页固定计划。

05素材缺口与注意事项

  • 素材缺口：0（6 台器械素材齐备；28 个动作全部为真人示范，无线稿兜底、无缺失）。
  • 臀腿动作库缺口已解除：已补充史密斯臀桥 / 髋推（史密斯机）与 45°臀腿举（臀推机 / 45°臀冲，无专用机可用史密斯机替代），髋伸主导动作从 2 个增至 4 个。
  • 决策点（待拍板）：史密斯深蹲、哑铃箭步蹲为膝屈主导动作，按「翘臀不粗腿」原则保持在默认组合之外（动作库保留，未来可作「练粗腿」备用模式）。证据：Contreras 2015/16 EMG 研究臀推臀大肌激活约深蹲 2 倍；2020 年训练女性研究深蹲组股四头肌肥大 12.2% vs 髋推组 2%。
  • 哑铃单臂划船示范图为图虫签名链接（有效期至 2027 年中），上线时应下载进 IndexedDB 离线缓存；备选 https://aka.doubaocdn.com/l/GovkVxocjn（已验证可用）。
